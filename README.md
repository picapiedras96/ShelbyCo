# ShelbyCo

## Summary
This project is a simple HTML and CSS website for my home town Shelbyvill, KY. This website is made more as a conept and practice of skills

## Tech Stack
 - HTML
 - CSS
 - IDE: Preffered IDE (VSCode)

 ## Development
 For local development get VSCode's live server extension and launch the website using live server, otherwise you can just launch the
 `index.html` from any preffered browser.
